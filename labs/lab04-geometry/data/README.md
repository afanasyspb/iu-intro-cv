## Своё фото

Сфотографируйте телефоном **плакат, этикетку, страницу или документ под углом** (до ~2000 px по длинной
стороне) и положите в `data/my-poster.jpg` — к нему ноутбук возвращается после TODO 2. Углы задаются
кликами в окне OpenCV (`RUN_CLICKER = True`, только локально) или руками в `MY_CORNERS` по осям на картинке.
Пропорции объекта (A4 — 210/297) впишите в `MY_ASPECT`: без них размер выхода берётся «по сторонам
в кадре», и на плакате лекции это врёт на 27 %.

Фото не обязательно: без него ячейка берёт плакат лекции, для зачёта это равноценно.

## Веб-камера (по желанию)

Ячейка `RUN_BEV_CAMERA = True` (только локально) строит **вид сверху на стол** с камеры: лист A4 на столе,
камера под углом, четыре клика по углам листа → картинка 1 px = 1 мм в реальном времени. Предмет рядом
с листом измеряется линейкой по экрану. Нужны лист A4 и свободная камера (закройте Zoom).

Нет камеры (Colab, `CVCOURSE_NO_CAMERA=1`) — ячейка пропускается; всё остальное занятие работает.
