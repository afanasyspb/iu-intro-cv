# Данные занятия 12: компактная синтетическая стереопара

Основной путь полностью офлайн. Генератор [../make.py](../make.py) входит в пакет
лабораторной; ноутбук и тесты вызывают `make_scene()` в памяти. После установки
зависимостей не нужны камера, сеть, KITTI-аккаунт или архив Middlebury.
Источник — собственный рендер двух текстурированных плоскостей; внешних изображений нет.

## Воспроизведение

Из каталога `labs/lab12-stereo/`, в окружении курса:

```powershell
python make.py
python -m pytest tests -q
```

Первая команда опционально записывает `data/left-raw.png`, `data/right-raw.png`,
`data/stereo.npz` и печатает SHA-256 массивов. Измеренные размеры файлов:
79 893, 79 580 и 10 096 байт, всего 169 569 байт. Эти производные не требуются
для запуска ноутбука и не хранятся в Git; исходник генератора находится **рядом
с ноутбуком**, вне игнорируемой папки данных. В `stereo.npz` — все поля сцены,
кроме изображений; читать через `np.load(..., allow_pickle=False)`.

Окружение измерения: OpenCV `4.14.0`, дистрибутив
`opencv-contrib-python==4.14.0.94`, Python 3.12. Зерно генератора — 12.
Зерно 71 используется отдельно для проверки переноса выбранной конфигурации.

## Геометрия и системы координат

- Размер `(W,H)=(384,240)`; сырые кадры uint8, один канал.
- В исходных камерах `fx=fy=400 px`, `cx=192`, `cy=120`; дисторсия нулевая.
  Правая камера повёрнута: Rodrigues `[0.012,0.025,-0.018]` rad.
- Мир совпадает с исходной левой камерой. Центр правой камеры `[0.12,0,0] m`,
  `T=-R @ C_right`, преобразование `X_right=R @ X_world+T`.
- Плоскости в мире: Z=2 и 4 m; ближняя панель ограничена
  `-0.18<X<0.54`, `-0.36<Y<0.36`. Текстуры — детерминированные случайные массивы.
- `left/right` — **до ректификации**. `gt`, `depth_gt`, `valid/visible` —
  **в сетке ректифицированной левой камеры** с `CALIB_ZERO_DISPARITY`, `alpha=0`.
  GT рассчитан пересечением лучей с плоскостями, отдельно от remap изображений.
  `gt=u_left-u_right` в px; `depth_gt` — осевая Z в новой левой камере, в метрах.
  Не применяйте к этому GT повторно карты ректификации исходных кадров.
- `visible` исключает фон, закрытый панелью в правом виде, и выход за правый кадр.
  `valid` дополнительно фиксирует `80<=u<376`, `8<=v<232` для всех конфигураций
  поиска до 64 px. На этой области **64 427 пикселей**. Границы панели не вырезаются.
  Маска не зависит от prediction, confidence WLS или выбранных параметров.

После ректификации `f=426.093850993 px`, `B=0.12 m`, `doffs=0 px`.
Метрический масштаб известен из генератора, а не восстановлен из F.

## SHA-256: измеренные контрольные суммы

Хешируется `np.ascontiguousarray(array).tobytes()` в C-порядке, **без заголовков
PNG/NPZ**. Все массивы имеют форму `(240,384)`; для float явно используется
little-endian float32 (`<f4`), для `valid` — bool, один байт на элемент.
Так контроль проверяет сами данные независимо от упаковки PNG/ZIP.
Те же суммы зафиксированы в автономных тестах.

| Поле | dtype | SHA-256 |
|---|---|---|
| `left` | uint8 | `d82652c48a0e8ec160e22dfac1b9161ac8ef7cb65dceb2d0cab7984d9ca8302e` |
| `right` | uint8 | `70738ec4baa987d79990aad0d6d25ae13319fd713e6c03360af986bbbd900459` |
| `gt` | <f4 | `3fa843c9acfbf46a59c96f8d29e1d8f3fc62b4a8c01aea3f2737165a3832e2ba` |
| `valid` | bool | `fb7f225ddc8667a1c29cd9e100ebbd9daec6188a21c3672213ab9b4f53090128` |
| `depth_gt` | <f4 | `edc3adb28d976feaef3c79d39b3f67d79f0e601cb918fc17e50eb1e6d0c16a14` |

## Метрики и расширение

`bad2_pct` считает ошибкой строго `abs(pred-gt)>2 px`, а также невалидное
предсказание на валидном GT. Покрытие сообщается отдельно. Полный RMSE при
пропусках — `None`/JSON null; `rmse_valid_px` — только условная диагностика.
Результат SGBM/WLS переводится из int16 в px делением на 16 **после** WLS.
Карта KITTI GT имеет другое кодирование (деление на 256).

Для перехода к HW4 используйте его три встроенных `sample_data/case*`, описание
формата и ожидаемый вывод из `homeworks/hw4-calib3d/sample_data/README.md`.
Это другой набор. Middlebury 2014/KITTI Stereo 2015 — опциональное расширение
по README HW4; лабораторная не запускает их загрузку. На внешней паре проверяйте
координаты GT, маску, `doffs`, метры базы и ректификацию до расчёта метрик.
Реальные камера/датасеты этим синтетическим контролем не проверяются.
