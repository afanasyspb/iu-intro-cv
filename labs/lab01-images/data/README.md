# Данные занятия 1

**Скачивать ничего не нужно.** Занятие 1 работает без сети — это сознательно:
первая пара не должна упираться в университетский Wi-Fi.

## Откуда берётся кадр

Ноутбук пробует три источника по очереди:

| Приоритет | Источник | Условие |
|-----------|----------|---------|
| 1 | `data/my_photo.jpg` | вы положили сюда своё фото |
| 2 | веб-камера, один кадр | локальный запуск, камера свободна |
| 3 | синтетическая сцена | всегда работает, в том числе в Colab |

**Своё фото интереснее:** контактный лист из настоящего снимка осмыслен,
из синтетики — нет. Любой формат, который читает OpenCV: JPEG, PNG, BMP, TIFF.
Кадр всё равно приводится к 640 × 440, так что размер исходника не важен.

## Почему не в репозитории

`data/*` в `.gitignore`. Изображения в git — это распухание истории:
бинарный файл не сжимается дельтами, и каждая правка добавляет полный размер.

## Если камера не открывается

Почти всегда причина одна: **предыдущая ячейка не отпустила захват.**
Перезапустите ядро. В курсе для чтения видео используется
`cvcourse.io.video_frames` — он освобождает камеру сам, даже если цикл прерван.

В Colab потокового видео нет вообще — сработает третий источник.
