## Стек кадров для шума

TODO 3 снимает **32 кадра неподвижной сцены с веб-камеры** (первые 16 выбрасываются:
автоэкспозиция ещё подстраивается). Что важно:

- камера свободна: закройте Zoom/браузер с камерой, при «камера занята» — Restart Kernel;
- **сидите неподвижно** и не махайте руками: движение в кадре — не шум, а сигнал;
- свет обычный комнатный; в полной темноте кадр уходит в чёрный и корзин яркости не будет.

равноценно: числа другие, вопрос тот же.
