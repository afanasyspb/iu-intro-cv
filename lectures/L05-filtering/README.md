# L5 — Пространственная фильтрация

| Что | Где |
|-----|-----|
| Слайды | `slides.pdf` — 49 слайдов (лекция — вт 29.09) |
| Живой код лекции | `demo/01_linear.py` — демо-блок 1 (корреляция против свёртки, σ Гаусса по метрике, сепарабельность и время, три режима границы) · `demo/02_nonlinear.py` — демо-блок 2 (таблица «шум × фильтр → PSNR», `sigmaColor` билатерального, `matchTemplate` при другом свете, PSNR против SSIM) |
| Данные демо | `demo/iu-building.jpg` — фотография здания ИУ, 1920 × 1279 (читается в сером); шум трёх моделей порождается в скриптах с фиксированными зёрнами, шаблон для `matchTemplate` — кроп 96 × 96 «люди на лестнице» с углом (560, 960) |
| Занятие с ассистентом | `labs/lab05-filters/` — «Свёртка и фильтры», клиника ДЗ 1 |
| Чтение к следующей паре | Szeliski, *Computer Vision: Algorithms and Applications*, 2nd ed., §3.4 (Фурье) и §3.5 (пирамиды) |

Запуск демо из корня репозитория (окружение — по `docs/setup-guide.md`):

```bash
python lectures/L05-filtering/demo/01_linear.py
python lectures/L05-filtering/demo/02_nonlinear.py
```

Скрипты печатают те же числа, что стоят на слайдах. Тайминги (демо 1.3, 2.3)
зависят от машины — на слайде порядок величины; PSNR и SSIM считаются функциями
`cvcourse.metrics`, одинаковыми для лекции, занятия и ДЗ.
