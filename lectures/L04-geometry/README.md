# L4 — Геометрические преобразования и ресемплинг

| Что | Где |
|-----|-----|
| Слайды | `slides.pdf` — 75 слайдов (лекция — вт 22.09) |
| Живой код лекции | `demo/01_transforms.py` — демо-блок 1 (поворот с сохранением кадра, четыре точки → фронтальный вид, что сохраняет гомография, цена варпа) · `demo/02_warping.py` — демо-блок 2 (прямой варп и дыры, свой билинейный `remap`, четыре интерполяции в числах, уменьшение и флаг `INTER_AREA`) |
| Данные демо | `demo/iu-building.jpg` — фотография здания ИУ · `demo/poster-angle.jpg` — тот же кадр с плакатом под углом (углы плаката: (560, 330), (1250, 220), (1290, 1010), (600, 840)) и `demo/poster-gt.png` — плакат «в лоб», эталон · `demo/road-cam.jpg` — синтетический кадр с камеры робота для bird's-eye view (fx 1663, высота 1.2 м, наклон 12°) · `demo/text-page.png` — страница текста для сравнения интерполяций |
| Занятие с ассистентом | `labs/lab04-geometry/` — «Геометрия на плоскости» |
| Чтение к следующей паре | Szeliski, *Computer Vision: Algorithms and Applications*, 2nd ed., §3.2 (линейная фильтрация) |

Запуск демо из корня репозитория (окружение — по `docs/setup-guide.md`):

```bash
python lectures/L04-geometry/demo/01_transforms.py
python lectures/L04-geometry/demo/02_warping.py
```

Скрипты печатают те же числа, что стоят на слайдах. Тайминги (демо 1.4, 2.2, 2.3)
зависят от машины — на слайде порядок величины; PSNR в демо 2.4 считается против
эталона Lanczos из Pillow, как в демо 2.2 лекции 1.
