# data/ — ваш набор кадров

Восемнадцать своих снимков листа A4 (см. README задания, §2): `01.jpg … 15.jpg` — с листом,
`16.jpg … 18.jpg` — негативные, и разметка `corners.json`, которую пишет команда

```bash
python docscan.py annotate data/*.jpg --ann data/corners.json
```

Уменьшите снимки до ≤ 2000 px по длинной стороне и ≤ 1 МБ каждый (JPEG, качество 85–90) **до**
разметки: углы размечаются в пикселях того файла, который лежит здесь.

В **этом** репозитории (ваш репозиторий Classroom) кадры и разметка коммитятся: без них проверяющий
не повторит ваши числа. В репозитории курса папка `data/` под `.gitignore` — там лежит только этот файл.
