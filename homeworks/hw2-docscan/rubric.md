## A. Работоспособность на кадрах проверяющего — 30

Набор проверяющего: пять кадров с листом (другой стол, другой свет, закрытый угол, лист под 45°)
и два без листа, у всех углы известны; короткий ролик. Сканер запускается с ключами из раздела
«Настройка» вашего отчёта — **одна настройка на все кадры**; раздел пуст — с ключами по умолчанию.

| Что запускается | Баллов | Как считается |
|-----------------|--------|---------------|
| `eval` в режиме `auto` | 14 | по 2 балла за кадр: с листом — IoU ≥ 0.9, без листа — ответ «не найдено» |
| путь `contour` отдельно | 3 | лист найден (IoU ≥ 0.9) не меньше чем на трёх кадрах из пяти; на двух — 1 балл |
| путь `hough` отдельно | 3 | то же; зерно по умолчанию |
| `scan` на двух кадрах | 5 | пропорции выхода — по `--aspect`; текст читается; на кадре с тенью тень не стала чернилами |
| `video` на ролике | 5 | идёт до конца без падения (2), рамка держится на листе (1), в режиме `auto` ≥ 10 кадров в секунду (2) |

Программа падает, выдаёт четырёхугольник на весь кадр или «бабочку» вместо скана — 0 за строку.

## Штрафы и нули

- Опоздание: −10 % от полученного балла за каждый начатый день, максимум 5 дней (см. README, §7).
- Заимствование без ссылки, чужой код, неспособность объяснить свой код при показе — **0 за работу**.
- Кадры не свои (стоки, интернет, кадры курса вместо своих) — −10 из C и вопрос при показе.
- Набор без трудных кадров (все листы на тёмном столе при дневном свете) — до −5 из C: сравнивать пути не на чем.
