### Оценка

| Что | Вес |
|-----|-----|
| Занятия с ассистентом (14 × 2 %) | 28 % |
| Домашние задания (4 × 8 %) | 32 % |
| Quiz (5 × 4 %) | 20 % |
| Письменный экзамен | 20 % |
| Бонусы | до +10 % |

- **Бонус за скорость:** первые 5 человек, сдавших каждое ДЗ (по автоматическому
  слепку GitHub Classroom), получают **+1 %** к итоговой оценке — до +4 % за семестр.
  Бонус засчитывается, если работа набрала не меньше половины баллов.
- **Отдельной защиты ДЗ нет:** в течение семестра каждый студент показывает
  и рассказывает ассистенту одно из своих ДЗ прямо на занятии. Занятие 15 — резерв
  для тех, кто не успел; дополнительных баллов оно не даёт.

## Библиотека `cvcourse`

Четыре модуля, которые снимают четыре источника потерянного времени:

```python
from cvcourse import io as cio, viz, metrics, datasets

img  = cio.imread("data/scene.png")        # внятная ошибка вместо молчаливого None
viz.grid({"вход": img, "результат": out})  # без BGR/RGB-ошибок, работает и в Colab
metrics.psnr(a, b)                         # метрики, посчитанные одинаково у всех
datasets.fetch("middlebury-motorcycle")    # кэш и контрольные суммы
```

Каждая метрика знает свою шкалу: в docstring написано, какое значение считается
хорошим. Метрика без представления о её шкале бесполезна.

## Версия OpenCV закреплена

```
opencv-contrib-python==4.14.0.94
```

Не «4.14 или новее» и не 5.x. В OpenCV 5.0 сломана обратная совместимость —
`cv2.HoughLinesP` возвращает `(N, 4)` вместо `(N, 1, 4)`, и примеры из туториалов
падают. Эталонные числа в ассертах привязаны к этой сборке.

`contrib` обязателен: без него нет `cv2.ximgproc` (WLS-фильтр, занятие 12)
и `cv2.aruco` (ChArUco, занятие 11).

## Правила сдачи

- Домашние задания — через **GitHub Classroom**, один репозиторий на студента,
  автоматический слепок по дедлайну.
- Занятия с ассистентом **не сдаются**: зачёт ставится в классе. Отработки нет —
  это оценка за активность.
- Использование ИИ-помощников разрешено — [позиция курса](AI_USAGE_TEMPLATE.md).
  Письменных деклараций нет: вы отвечаете за каждую строку, а чем пользовались
  и как — расскажете при показе ДЗ.
- Плагиат и сдача чужого кода — ноль за работу и разбор на кафедре.
